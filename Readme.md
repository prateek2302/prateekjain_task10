# Laundry Services - Hero Image Animation

## Objective
Apply a smooth CSS `@keyframes` animation to the hero section image replicating an orbital path coupled with squeeze-and-stretch effects.

## Features
- **Orbital Motion**: Moves the image in a gentle circular path using `translate(x, y)` and subtle tilt `rotate(...)`.
- **Squeeze & Stretch**: Modulates dimensions at `25%` and `75%` marks using non-uniform `scale(x, y)` transforms.
- **Infinite Loop**: Configured with `6s ease-in-out infinite` for continuous fluid motion.
- **Responsive**: Retains proper aspect ratio and bounds across desktop and mobile screens.
